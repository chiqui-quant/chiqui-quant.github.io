Chapter 1: Normed Spaces

  • What is a vector space?
  • What is a norm and what is a normed space?
  • What are some examples of normed spaces? $(\mathbb{R}^{n},\lVert \cdot \rVert_{e})$, $(\mathbb{R}^{n},\lVert \cdot \rVert_{1})$, $(\mathbb{R}^{n},\lVert \cdot \rVert_{\infty})$, $(\ell^{1}(\mathbb{N}),\lVert \cdot \rVert_{1})$, $(\mathscr{C}(I),\lVert \cdot \rVert_{1})$, $(\mathscr{C}(I),\lVert \cdot \rVert_{\infty})$

A normed space is a space on which you can define a norm. Now, we should try to understand what is a space and what is a norm. Note that this is not the most general possible framework. More general are topological spaces, inside them we find metric spaces. But since they present some strange pathological things we start directly from the even smaller subset of normed spaces.

We assume the space (set) of elements we are dealing with is a vector space. In practice we will always just use $\mathbb{R}$ vector spaces, but the theory can be extended for $\mathbb{C}$.

What is a vector space? A collection of elements with two operations.

[D.][Vector Space]
A $\mathbb{K}=\mathbb{R}$ (or $\mathbb{K}=\mathbb{C}$) vector space, where $\mathbb{K}$ is a field and $X$ is a non-empty set on which we can define two operations:
  • Sum (addition): given $x,y\in X$ we can define a third element $x+y\in X$ which is the sum of $x$ and $y$. Note: the third element “$x+y$” is treated as a single entity/object, if you want you can call it $z=x+y$.
  • Scalar multiplication: given $X\in X, \alpha\in \mathbb{K}$ we can define $\alpha\cdot x\in X$ as the product of $\alpha\in \mathbb{K}$ with $x\in X$.

These operations satisfy the following properties (note that these are part of the definition): (0) Closed $+$ and $\cdot$: if you take $x\in X,y\in X$ the operation is still inside the set ie. $x+y\in X$ and if $x\in X,\alpha\in \mathbb{K}\Rightarrow \alpha\cdot x\in X$ (ie. all elements are still inside the set when scaled).
